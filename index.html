About

I'm a software engineer working across React, .NET, ASP.NET, Blazor, Svelte 5, TypeScript and SQL, building scalable full-stack applications and interactive learning platforms.

Most of my recent work sits at the intersection of frontend architecture and real-time systems: migrating C#-based applications to React, building a timeline-based animation editor, and shipping config-driven classroom games that run inside an iframe-embedded host application.
